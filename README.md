Lago Piloti
===========

Lago Piloti ist eine mit Vue und Ionic entwickelte mobile Anwendung, die Wakeboard- und Wakesurf-Enthusiasten sowie Bootsführer mit nützlichen Informationen rund um ihren See unterstützt. Der Hauptfokus der App liegt auf einer interaktiven Karte mit verschiedenen Points of Interest (POIs) sowie zusätzlichen Funktionen wie einer Stoppuhr für mehrere Personen und einer Geschwindigkeitsanzeige.

Features
--------

### ✨ Interaktive Karte

-   Anzeige von **Points of Interest (POIs)** wie:

    -   Häfen

    -   Tankstellen

    -   Kursschiffe und deren Routen

-   Darstellung von **Uferzonen** mit Geschwindigkeitsbegrenzungen, sodass der Kapitän stets informiert ist, wo welche Regeln gelten

### ⏱️ Stoppuhr-Funktion

-   Speziell für Wakeboarden und Wakesurfen

-   **Mehrpersonen-Unterstützung** zur Erfassung von Fahrzeiten

### ⚡ Geschwindigkeitsanzeige

-   Anzeige der aktuellen Bootsgeschwindigkeit

### ⚓ Bootsrelevante Informationen

-   Nützliche Daten und Hinweise für Bootsfahrer

-   Möglichkeit, spezifische Orte und Services zu finden

Installation
------------

### Voraussetzungen

-   Node.js & npm installiert

-   Ionic CLI global installiert

### Setup

```
# Repository klonen
git clone https://github.com/Yannic-reust/lagoPilot
cd lago-piloti

# Abhängigkeiten installieren
npm install
```

### Entwicklung starten

```
ionic serve
```

### Build für mobile Geräte

```
ionic build
ionic cap sync
```

Technologie-Stack
-----------------

-   **Vue.js** - Frontend Framework

-   **Ionic** - Mobile UI-Komponenten & native Schnittstellen

-   **Capacitor** - Native Funktionalitäten
